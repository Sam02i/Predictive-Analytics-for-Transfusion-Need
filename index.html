About this number: this gauge runs the actual trained Random Forest, exported to JavaScript and executed right here in your browser. It was trained on a small 206-row demo dataset (14 positive cases), evaluated with cross-validation — a real but modest result given the sample size (see Methodology). Age is shown above for context only; it isn't one of the model's 6 trained features. Worth knowing: with so few positive cases to learn from, some sliders (heart rate in particular) don't move the estimate in a strictly textbook direction — that's the real model being honest about a small, noisy dataset, not a display bug. Treat this as a portfolio demonstration, not a diagnostic tool.

The short version: a Random Forest and a Logistic Regression baseline were both evaluated with stratified 5-fold cross-validation, with SMOTE applied fresh inside each fold to avoid leakage. Exact ROC-AUC figures are finalized in the project notebook, which also documents two rounds of data-leakage detection and correction, a database join-explosion bug that was found and fixed, and an honest discussion of what a 14-positive-case dataset can and can't support. Full details, cross-validation results, the calibration curve, and the threshold analysis are in the notebook alongside this demo — this page is the interactive front door, not a replacement for the write-up.
